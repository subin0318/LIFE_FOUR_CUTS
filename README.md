# 💻 개발 언어
![HTML , CSS](https://github.com/subin0318/LIFE_FOUR_CUTS/assets/156440512/5fb6c429-17b8-4c1c-aebd-bb1e7e6a9756)

## 공부 내용

1. 요소 초기화를 하는 이유
2. 가운데 정렬
3. margin과 padding 이론 적용
4. 선택자, 클래스 선택자를 사용하는 이유
5. 속성값 적용
6. 이미지 삽입
7. `position: relative` 적용

## 개선점

1. CSS 선택자를 클래스 선택자로 사용하고자 합니다.
2. 속성값 적용에 아직은 미숙합니다.
3. 포지션 및 가운데 정렬에 대한 이론을 더 공부해야 합니다.
4. HTML, CSS로만 만들었지만 추후 자바스크립트 공부 후 새로운 프로젝트에 도전할 예정입니다.

## 결과

1. 단순 이론 공부는 개발에 전혀 도움이 안된다는 것을 다시 한 번 느꼈습니다.
2. 새로운 프로젝트를 만들 수 있어서 기쁨입니다.
3. 앱 개발자로 준비하는데 한 걸음 더 나아간 것 같습니다.
4. '인생네컷'에 기본 프레임을 만들어 놓으니 새로운 프레임을 계속 만들 수 있습니다. 길이부터 이미지 삽입까지 다양한 기능을 추가할 수 있습니다.
