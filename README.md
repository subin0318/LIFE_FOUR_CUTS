# 📖 개발 계기
2024년 1월 1일부터 ~ 3월 31일 까지 공부한 html, css 를 실습 하고싶어 만든 프로젝트.

사진을 찍고 싶을 때 종종 찾는 '인생네컷'을 자세히 보니 몇 가지 단점이 있다. 찍을 곳이 한정적일 뿐 아니라 내가 원하는 프레임을 얻지 못할 수도 있고, 찍을 때 타이머가 있는 것이 상당히 불편하다. 그래서 이러한 문제를 해결하고자 만들어 보았습니다.

# 💻 개발 언어
![HTML , CSS](https://github.com/subin0318/LIFE_FOUR_CUTS/assets/156440512/5fb6c429-17b8-4c1c-aebd-bb1e7e6a9756)

## 공부 내용

1. 요소 초기화를 하는 이유
2. 가운데 정렬
3. margin과 padding 이론 적용
4. 선택자, 클래스 선택자를 사용하는 이유
5. 속성값 적용
6. 이미지 삽입
7. `position: relative` 적용

## 기능

1. 기본 프레임이 있어 원하는 길이 및 프레임을 내 취향대로 설정할수 있다 
2. 내가 원하는 사진을 마음대로 넣을수 있다 (사진 url만 넣으면 된다)
 

## 개선점 및 느낀점

1. CSS 선택자를 클래스 선택자로 사용하는 실수를 한다.
2. 속성값 적용에 아직은 미숙하다.
3. 포지션 및 가운데 정렬에 대한 이론을 더 공부해야 한다.
4. HTML, CSS로만 만들었지만 추후 자바스크립트 공부 후 새로운 프로젝트에 도전할 예정이다.
